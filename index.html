Installation Instructions

How to Install Hosteria

  1. Download the official MicroOS image: 
    wget https://download.opensuse.org/ports/aarch64/tumbleweed/appliances/openSUSE-MicroOS.aarch64-RaspberryPi.raw.xz

    For x86_64, use the SelfInstall ISO instead.

  2. Flash to SD card or USB: 
    xz -d openSUSE-MicroOS.aarch64-RaspberryPi.raw.xz
sudo dd if=openSUSE-MicroOS.aarch64-RaspberryPi.raw of=/dev/sdX bs=4M status=progress
sync

    Replace /dev/sdX with your actual device.

  3. Create a combustion partition on a USB stick: 
    sudo mkfs.ext4 /dev/sdY1
sudo e2label /dev/sdY1 combustion
sudo mount /dev/sdY1 /mnt
sudo mkdir -p /mnt/combustion
sudo cp ~/Downloads/hosteria-combustion.sh /mnt/combustion/script
sudo umount /mnt
  4. Insert both SD card and USB stick into your device and power on.
  5. Wait 5-10 minutes for first boot setup.
  6. Access Cockpit:

    Open https://hosteria.local:9090 from your phone or laptop.

    Login with user hosteria and your password.
